# Logeshvaran Portfolio Website

This project is based on the HTML file you supplied and styled with a responsive light theme.

## Project structure
- `index.html` — portfolio content
- `assets/style.css` — responsive light-theme styling
- `assets/script.js` — mobile navigation, current year and email enquiry form
- `assets/Logeshvaran_Resume.pdf` — add your own resume PDF here
- `assets/images/` — local image assets folder, including `nas-san-storage.svg` and `certifications-providers.png`

## Before publishing
1. Copy your resume PDF into `assets/` and name it `Logeshvaran_Resume.pdf`.
2. Open `assets/script.js` and contact form is configured for `logeshvaranit@gmail.com`.
3. Replace the LinkedIn URL if needed.
4. Review all dates, metrics and certification claims. The HTML supplied states 23 certifications and other figures; verify them before publishing.
5. Service-card photos currently use external Unsplash image URLs. To make all photos local, download your chosen licensed images into `assets/images/` and update the image `src` values in `index.html`.

## Run locally
Keep the folder structure intact and open `index.html` in a browser.

## Publish
Upload the complete project folder, including `assets/`, to your static web host.

- `assets/images/hero-infrastructure.png` — hero infrastructure visual, with AWS Cloud highlighted in an HTML badge.


## Prepare Email Enquiry button
The contact form validates the required fields and opens a Gmail compose window addressed to `logeshvaranit@gmail.com`, with the subject and message prefilled. The visitor must be signed in to Gmail (or sign in) and click Send. This is a front-end email handoff, not automatic server-side delivery.
